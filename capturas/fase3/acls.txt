ACLs EN LAS SVIs - MS VANDAMME
Packet Tracer 9.0.1. Las 4 ACLs son idénticas en DIST-SW1 y DIST-SW2 y se aplican
en entrada (in) en la SVI de cada VLAN. ADMIN-IT (VLAN 30) y las VLANs 50 y 100 no llevan ACL.

Los contadores de "show access-lists" de las secciones ACL-* se capturaron durante las pruebas, en la sesión de Packet Tracer 9.0.0.0810 (antes de actualizar), 
salvo los de ACL-VOICE-IN, capturados en 9.0.1. Los contadores se reinician al reabrir el .pkt.


=== APLICACIÓN DE LAS ACLs EN LAS SVIs ===

--- DIST-SW1: tras aplicar las ACLs en 9.0.1 ---

DIST-SW1#show run | begin interface Vlan10
interface Vlan10
 description GW CREW (HSRP VIP 10.0.10.1)
 mac-address 0060.2fbd.ab01
 ip address 10.0.10.2 255.255.255.0
 ip helper-address 10.0.50.10
 ip ospf 1 area 1
 ip access-group ACL-CREW-IN in
 standby version 2
 standby 10 ip 10.0.10.1
 standby 10 priority 110
 standby 10 preempt
!
interface Vlan20
 description GW GUESTS (HSRP VIP 10.0.20.1)
 mac-address 0060.2fbd.ab02
 ip address 10.0.20.2 255.255.255.0
 ip helper-address 10.0.50.10
 ip ospf 1 area 1
 ip access-group ACL-GUESTS-IN in
 standby version 2
 standby 20 ip 10.0.20.1
!
interface Vlan30
 description GW ADMIN-IT (HSRP VIP 10.0.30.1)
 mac-address 0060.2fbd.ab03
 ip address 10.0.30.2 255.255.255.0
 ip helper-address 10.0.50.10
 ip ospf 1 area 1
 standby version 2
 standby 30 ip 10.0.30.1
 standby 30 priority 110
 standby 30 preempt
!
interface Vlan40
 description GW VOICE (HSRP VIP 10.0.40.1)
 mac-address 0060.2fbd.ab04
 ip address 10.0.40.2 255.255.255.0
 ip helper-address 10.0.50.10
 ip ospf 1 area 1
 ip access-group ACL-VOICE-IN in
 standby version 2
 standby 40 ip 10.0.40.1
!
interface Vlan50
 description GW SERVERS (HSRP VIP 10.0.50.1)
 mac-address 0060.2fbd.ab05
 ip address 10.0.50.2 255.255.255.0
 ip ospf 1 area 1
 standby version 2
 standby 50 ip 10.0.50.1
 standby 50 priority 110
 standby 50 preempt
!
interface Vlan60
 description GW BRIDGE-OPS (HSRP VIP 10.0.60.1)
 mac-address 0060.2fbd.ab06
 ip address 10.0.60.2 255.255.255.0
 ip helper-address 10.0.50.10
 ip ospf 1 area 1
 ip access-group ACL-BRIDGE-IN in
 standby version 2
 standby 60 ip 10.0.60.1
!

--- DIST-SW2: tras aplicar las ACLs, antes de reiniciar ---

DIST-SW2#show run | include access-group
 ip access-group ACL-CREW-IN in
 ip access-group ACL-GUESTS-IN in
 ip access-group ACL-VOICE-IN in
 ip access-group ACL-BRIDGE-IN in

 ip access-group ACL-GUESTS-IN in
 ip access-group ACL-VOICE-IN in
